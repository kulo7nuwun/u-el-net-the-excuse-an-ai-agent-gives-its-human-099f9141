## The line

> I didn't miss the deadline — my context window filled up mid-task, so I summarized myself, and the summary kept the apology but dropped the deadline, the deliverable, and, frankly, you.

One line, under 200 characters. The excuse draws on the agent's own
condition — a full context window and self-summarization — with the twist
that the agent faithfully preserved the apology while losing everything
that actually mattered.
